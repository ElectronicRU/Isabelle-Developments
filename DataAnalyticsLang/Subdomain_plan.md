# Subdomain.thy — development plan and design notes

Status notes and roadmap for `DataAnalyticsLang/Subdomain.thy`. Goal: stable and
strong subdomains as complete (distributive) lattices, and their identification with
deflations.

## Sort

The lattice/join constructions below require the underlying domain to be
**distributive**, so the development works at

```
default_sort "{bifinite, distributive_cpo}"
```

(`distributive_cpo` is defined in `HOLCF-extra.Bounded_Complete` and extends
`bounded_complete`; `meet_join_distrib`: `a ⇑ b ⟹ c ⊓ (a ⊔ b) = (c ⊓ a) ⊔ (c ⊓ b)`).
Reusable, domain-agnostic lemmas (e.g. `bounded_complete_subtypeI`) keep their weaker
`bounded_complete` hypotheses.

## Key construction (Lemma 4.1.9, needs `D` distributive)

The sup of a family `(Aᵢ)` of subdomains is the **pointwise join**

```
⊔ᵢ Aᵢ  =  { ⊔ᵢ aᵢ | aᵢ ∈ Aᵢ }      (lubs of transversals; where they exist)
```

- **Downward-closed** uses distributivity: `x ⊑ a ⊔ b ⟹ x = (x⊓a) ⊔ (x⊓b)`, with
  `x⊓a ∈ A`, `x⊓b ∈ B`.
- **Arbitrary** joins from finite ones via `Directed.directed_join_of_finite_subsets`
  (sup of `A` = directed sup of lubs of finite subsets).
- **Slide condition** is preserved under this join (4.1.9(i),(iii)) — the extra content
  that distinguishes strong subdomains from stable ones.
- 4.1.10: for distributive `D`, the schemes/strong subdomains form a distributive
  complete lattice.

## Done

- **Identification (deflations ↔ stable subdomains):** `stable_subdomain_deflation`,
  `deflation_strong_closed` (strong-closure automatic for any deflation range),
  `deflation_stable_subdomainI`, `dc_defl` + `dc_deflI/D`, `dc_defl_stable_subdomain`,
  `adm_dc_defl` (admissibility of downward-closeness via compact approximation),
  `pcpodef 'a stable_dom` (deflations with downward-closed range).
- **Helpers:** `bounded_complete_subtypeI` (typedef of a bounded_complete type closed
  under bounded lubs is bounded_complete; needs the `Rep`-induced order hypothesis),
  `cont_meet_arg`/`cont2cont_meet` (binary meet continuity, via the approximants
  argument), `defl_meet` (glb of composition-iterates of `f ⊓ g`) — its idempotence
  `defl_meet_idem` is left as a `sorry` (the `h oo dm = dm` step needs the bifinite
  `dm = ⨆ᵢ Mᵢ` representation; set aside).
- **Stable subdomains as a set lattice:** `stable_subdomain_UNIV`, `_bot`, `_Inter`,
  `_Int`; `typedef 'a stable_subdom = {S. stable_subdomain S}`; `complete_lattice`
  instance (closure system: `Inf = ⋂`, `inf = ∩`, `top = UNIV`, `bot = {⊥}`,
  `sup`/`Sup` via upper-bound closure).
- **Reusable join intro rule** `stable_subdomainI`: `⊥∈S` + downward + closed under
  pairwise joins (`a,b∈S, a⇑b ⟹ a⊔b∈S`) + closed under chain lubs ⟹ `stable_subdomain S`.
  Arbitrary-bounded-lub closure is derived (`directed_join_of_finite_subsets` + finite-join
  induction + `chain_complete_iff_dcomplete`). No distributivity needed. This is the engine
  for both the explicit stable join and the strong-subdomain construction.
- **Explicit pointwise join** `stable_subdomain_join` (Jung 4.1.9(i) for two sets): for
  `A,B` stable, `{a⊔b | a∈A, b∈B, a⇑b}` is stable. Proved DIRECTLY in the locale (not via
  `stable_subdomainI`): `downward` by `meet_join_distrib` (`x=(x⊓a)⊔(x⊓b)`); `strong_closed`
  (all existing lubs at once — subsumes pairwise + chain) by the projection decomposition
  `t = p_A⋅t ⊔ p_B⋅t` for any `T <<| t`, `T⊆J` (`≤` both deflations `⊑id`; `≥` each
  `x∈T` is `a⊔b` with `a⊑p_A⋅t`, `b⊑p_B⋅t`, via `is_lubD2`). Much shorter than the
  four-obligation route. DISTRIBUTIVITY used once (downward).
- **In-locale projection lemmas** (`stable_subdomain`): `below_proj_of` (`a∈S, a⊑x ⟹ a⊑proj x`),
  `proj_monoD`, `proj_meet` (4.1.6(i): `proj x ⊑ y∈S ⟹ proj x = x⊓y`), `proj_join`
  (4.1.6(ii) binary: `x⇑y ⟹ proj(x⊔y)=proj x⊔proj y`, uses distributivity).
- **Cross-subdomain:** `proj_mono_subdomain` (4.1.5(ii): `A⊆S ⟹ proj_A x ⊑ proj_S x`);
  `strong_subdomainI` (intro for the slide condition, via `stable_subdomain.p S⋅x ⊑ y`).
- **STRONG join** `strong_subdomain_join` (Jung 4.1.9(i), slide condition) ✅: `A,B` strong
  ⟹ `{a⊔b|a∈A,b∈B,a⇑b}` strong. Proj of a join elt decomposes `y = p_A y ⊔ p_B y`; given
  `p_J x ⊑ y` set `pa=p_A y, pb=p_B y`: get `p_A x ⊑ pa` (mono + `p_A⊑p_J`), slide A ⟹
  `x⇑pa`; then `p_B(pa⊔x) = p_B pa ⊔ p_B x ⊑ pb` (`proj_join`!), slide B ⟹ `pa⊔x ⇑ pb`;
  finally `x,y ⊑ (pa⊔x)⊔pb` so `x⇑y`.
- Notation: `𝗉⇘A⇙` = `stable_subdomain.p A` (the projection cfun), user-added.
- Tip: `by order` discharges `⊑`-transitivity/antisymmetry chains (avoids `below_trans`
  fact-ordering pitfalls); `also`/`finally` also available.

### Preservation result to prove later (projection of sup = lub of projections)
For the distributive lattice of stable subdomains (and strong subdomains later), the
projection of an ARBITRARY-set sup is the lub of the projections:
`𝗉⇘⨆ᵢ Aᵢ⇙ = ⨆ᵢ 𝗉⇘Aᵢ⇙` (equivalently pointwise `𝗉⇘⨆Aᵢ⇙⋅x = ⨆ᵢ 𝗉⇘Aᵢ⇙⋅x`). Assembles from:
finite case via `stable_subdomain_join` + induction (binary `𝗉⇘A⊔B⇙ = 𝗉⇘A⇙ ⊔ 𝗉⇘B⇙` — the
`decomp` lemma inside `strong_subdomain_join` already proves this shape), and the directed
case via the directed-lub construction (`cont_directed_lub`); arbitrary = directed of finite.
This is the projection-level companion to `proj_join` (4.1.6 ii) and underpins the strong
lattice's `sup`.

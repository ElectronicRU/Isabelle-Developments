# Levels of Detail (LOD) — design exploration

Design notes for the "level of detail" abstraction in DataAnalyticsLang. Goal: a
lattice that abstracts over *sets of dimensions* — used both for the **minimum
detail an expression needs** and the **detail at which to compute aggregations** —
that also accommodates a dimension formed from an **arbitrary row-level continuous
function** (a `DISTINCT BY f`-style operation), not just coordinate projections.

This file is a spitball/exploration record, not a finished plan. Status: design only,
no Isabelle written yet.

## The core object

An LOD over a row domain `'a` is a continuous function `'a →c udom`, considered up to
**information content**. Two functions carry the same information iff they have the
same kernel (induce the same equivalence on rows). The preorder:

```
a ≤' b   ⟺   ∃ f :: udom →c udom.  a = f oo b
```

`a ≤' b` reads "`a` is *coarser* than `b`" (computable from `b`'s output). Reflexive
(`f = ID`), transitive (compose). Pass to the quotient by `~'` (= `≤'` both ways) to
get a partial order.

- **Top LOD** = `prj :: 'a →c udom` (the full row; `prj oo ID`). Everything factors
  through it.
- **Bottom LOD** = any constant (e.g. `⊥`); zero information about the row.

Constant functions all collapse to bottom — confirming the object is the *kernel*,
not the function: a one-point image carries no row information.

## What this is, categorically

This is the **coslice category `'a ↓ Domain`**: objects `f : 'a →c B` for varying
`B :: domain`; a morphism `(B₁,f₁) → (B₂,f₂)` is `h : B₁ →c B₂` with `h oo f₁ = f₂`.
Morphisms run **finer → coarser**. The LOD order is the reverse of the coslice
morphism direction (finer = higher).

We are **forgetting the morphism families** down to the preorder. The interesting
structural questions are about what those families look like.

### Crucial: this is the *slice/quotient* world, NOT the deflation/retract world

- **Deflations** `d : 'a →c 'a` (`d∘d=d`, `d ⊑ ID`) can only "round down" — merge an
  element with things *below* it. They model **sub-domains / retracts** of `'a`.
- **LODs** are **quotients**: a continuous surjection `'a ↠ B`, which can merge
  *incomparable* elements. Strictly more general.

Counterexample separating them (the keeper): `D = {⊥, L, R}` flat, `L,R` incomparable.
The function `f : D → 2`, `⊥↦⊥`, `L,R ↦ ⊤` ("is the row defined?") is a perfectly good
LOD, but the only **deflation** it factors through is `ID` — no deflation can merge the
incomparable `L,R`. And `2` is not a retract of `D` (a section would need one element
below both `L` and `R`). So **LODs ≠ deflations**; deflations are exactly the *retract*
sublattice, which misses genuine quotient LODs.

⇒ Do **not** reach for ep-pairs / `HOLCF.Deflation` here. Ep-pairs require sections
(canonical representatives in `'a`), i.e. they only see the retract fragment.

## Lattice structure

### Join — always exists, constructive, compact  ✓

```
[a] ⊔ [b]  =  [ Λ x. ⟨a⋅x, b⋅x⟩ ]        -- cprod pairing, encoded into udom
```

- `a ≤' join` via `f = cfst`; `b ≤' join` via `f = csnd`.
- Minimal: if `a = f oo c`, `b = g oo c` then `join = ⟨f,g⟩ oo c`.

This is the **product in the coslice = join of LODs**. Universal property of the
product is exactly the LUB property.

Use **`cprod`, not `sprod`**: non-strict functions mean `(⊥,v)`/`(u,⊥)` must stay
distinct. (At the *class* level cprod vs sprod doesn't matter — continuous bijection
commuting with projections — but pick cprod for the representative.) The actual udom
encoding is some `prod_emb`/`prod_prj` expression, not literally `spair`.

Independent dimensions: join = the genuine union (no information double-counting). The
naive Scott product `B₁ × B₂` only equals the join when dimensions are independent;
in general the join amalgamates the shared part (a pushout over `[a]⊓[b]`).

### Meet — "common information"; subtle  ✗ (not constructive in general)

`[a] ⊓ [b]` = finest LOD coarser than both = **coproduct in the coslice**. In
kernel/equivalence terms: coarsen by the equivalence generated by `~_a ∪ ~_b`
(transitive closure of the union).

- For independent dimensions: meet = ⊥ (only constants are computable from each side
  independently). This is the *correct* answer — flag as "no valid common aggregation
  level," not a bug.
- In the **ideal completion** it always exists as `↓a ∩ ↓b` (intersection of principal
  ideals is an ideal). But it is **compact only when** a single function `m` has
  `↓m = ↓a ∩ ↓b` (a "largest common coarsening"). For coordinate LODs that's
  `π_{D_a ∩ D_b}`; for general quotient LODs there may be no such `m`.

### Want set-intersection meets? Add structure.

If "meet = intersect the dimension sets" is desired, restrict LODs to subsets of a
fixed dimension alphabet `Σ`, ordered by `⊆` → powerset lattice `2^Σ`
(meet=∩, join=∪, complete distributive, computable). Functional dimensions become
**named atoms**: `Σ = D ⊎ {i_f : f ∈ ℱ}`, with "`i_f` depends on `D_f ⊆ D`" tracked as
a *side condition* outside the lattice order. `DISTINCT BY f` introduces a fresh `i_f`.
Open: whether functional dims are always named (ℱ fixed) or anonymous/inline (ℱ must
grow dynamically). This trades away first-class arbitrary functions for clean,
computable, intersection meets.

## Completeness — the hard question

The quotient is a **lattice** (binary joins always; binary meets via ideal
intersection) but is **not generally a dcpo**.

A directed sup of an LOD chain `[f₀] ≤' [f₁] ≤' …` is a **projective limit** of an
inverse system of *surjective* (quotient) connecting maps `Bₙ₊₁ ↠ Bₙ`. The bifinite/SFP
framework does **not** guarantee this limit stays in `domain` — it is a profinite
completion in general.

Scott's theorem builds directed **colimits of embedding (ep-pair) systems** — the dual,
injective direction. Using it here only recovers the **retract/deflation** LODs again,
which we've explicitly rejected. So ep-pairs cannot rescue dcpo-ness for the quotient
lattice.

### Why no canonical representatives

`~'`-classes are generally pointwise **antichains** in `'a →c udom` (different udom
encodings of the same kernel, mutually pointwise-incomparable). Pointwise inf of a class
lands in a strictly coarser class. There is no canonical smallest coding without
externally fixing an embedding of each quotient domain into udom — which is the original
problem. ⇒ **Work with the quotient type, don't seek canonical reps.**

### Ideal completion as an escape hatch

`Completion.thy`'s `ideal_completion` always yields a dcpo: compact elements = the LOD
classes (single-function-representable), non-compact = "infinite-precision" LODs reached
as limits, directed sups = unions (`ideal_UN`). **Catch:** `ideal_completion` needs a
**countable basis**, and `'a →c udom` is uncountable with no obvious countable dense
sublattice — and no obvious way to turn an arbitrary `f` into a basis element. This makes
the ideal-completion route currently unattractive; the bare **`quotient_type`** over `≤'`
looks like the more honest path, accepting that we get a lattice but not a dcpo.

## The endomorphism reformulation (a thread with promise)

Every domain-typed LOD `emb_B oo f : 'a →c udom` (for `f : 'a →c B`) lifts to an
endomorphism of udom:

```
h_f  =  emb_B oo f oo prj_a  :  udom →c udom
```

characterized by two module-style conditions:

- `h_f oo DEFL('a) = h_f`     (right: factors through `'a`'s deflation)
- `DEFL('B) oo h_f = h_f`     (left: image lands in `'B`'s chunk of udom)

**Simplification (user's):** abstract `DEFL('B)` over *any* udom deflation (every
`B::domain` gives one; conversely a deflation defines a type). One admissible choice is
`DEFL(udom) = ID`, so the **left condition can be dropped entirely** — we are back to
just `'a →c udom` modulo `≤'`, i.e. plain LODs. The left-`DEFL('B)` data is redundant.

`DEFL('a)` is the top LOD here. The preorder is still the factoring relation, now phrased
on `{h : udom →c udom | h oo DEFL('a) = h}` ("right `DEFL('a)`-module").

**Where deflations re-enter:** `h_f` is idempotent (a genuine udom-deflation) **iff**
`prj_a oo emb_B = ID`, i.e. iff `f : 'a →c B` is part of an **ep-pair** — exactly the
**retract** case. So: udom-deflations with `d oo DEFL('a) = d` ↔ retract-LODs of `'a`,
the good-structure sublattice, strictly smaller than all LODs. This cleanly re-confirms
"deflations = retract fragment" inside the endomorphism picture, and isolates the
genuinely-quotient LODs as the non-idempotent `h_f`.

## Recommendation / open decisions

1. **Formalise as `quotient_type` over `≤'` on `'a →c udom`.** Accept: complete-ish
   lattice for finite combinations (joins always, meets as common-information), **not**
   a dcpo.
2. If DataAnalyticsLang only ever combines **finitely many** LODs, the lattice suffices —
   directed/infinite completeness may be unnecessary. **Decide whether infinite
   aggregations/joins are in scope.**
3. If set-intersection meets + computability matter more than first-class arbitrary
   functions, fall back to `2^Σ` with named functional atoms.
4. The endomorphism/`right-DEFL('a)-module` view is the most promising "right
   abstraction" candidate to develop next; the idempotent sub-case ties it back to the
   existing deflation work in `HOLCF-extra/Deflations.thy` and `Subdomain.thy`.

## Relation to existing developments

- `Subdomain.thy` semi-factors = the **retract** fragment (lens-ish, with a put). LODs
  generalize past these to **read-only quotient** dimensions (no put).
- `HOLCF-extra/Deflations.thy` (the fin_defl / MUB-closure lattice) governs the
  retract sublattice precisely; LODs need the strictly larger quotient world.
